0.3 Bedienung dieser Webseite

Dieses Vorlesungsskript wird als Jupyter Book (MyST) bereitgestellt. Die Inhalte sind in Kapitel und Abschnitte gegliedert und über die Navigation links erreichbar.

Navigation¶

  • Die linke Seitenleiste zeigt alle Kapitel und Unterkapitel.

  • Mit den Pfeilen am Ende jeder Seite gelangen Sie zur vorherigen oder nächsten Seite.

  • Auf kleinen Bildschirmen kann die Seitenleiste über das Menüsymbol geöffnet werden.

Suche¶

  • Über die Suchfunktion können Sie Kapitel und Begriffe direkt finden.

  • Suchergebnisse werden während der Eingabe aktualisiert.

  • Ein Klick auf ein Ergebnis springt direkt zum passenden Abschnitt.

Code und Ausführung¶

  • Codeblöcke können mit dem Kopier-Button direkt in die Zwischenablage kopiert werden.

  • Einige Seiten enthalten Jupyter-Notebook-Inhalte.

  • Ob Code direkt im Browser ausgeführt werden kann, hängt von der jeweiligen Seite und der Konfiguration ab.

Beispiel:

print("Hello, World!")

Downloads und Quellen¶

Je nach Seite stehen zusätzliche Aktionen zur Verfügung, zum Beispiel der Download von Inhalten oder der Zugriff auf den Quelltext.

Selbststudium¶

Am Ende vieler Abschnitte finden Sie Self-Study Questions. Diese Fragen helfen beim Wiederholen und Vertiefen der Inhalte.

Challenge Questions sind optional und gehen über den Kernstoff hinaus.
