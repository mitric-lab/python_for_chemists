3.1 Regression

In supervised learning, we model the relationship between inputs xxx and outputs yyy with a function fff. If yyy is continuous, the task is regression; if yyy is discrete, the task is classification.

Theoretical Foundations¶

Linear Regression¶

For scalar inputs, the one of the simplest models assumes a linear relationship between xxx and yyy:

y^=β0+β1x\hat{y} = \beta_0 + \beta_1 xy^​=β0​+β1​x

In a plot of yyy versus xxx, this model is a straight line with slope β1\beta_1β1​ and intercept β0\beta_0β0​. Given NNN input-output pairs (xi,yi)(x_i, y_i)(xi​,yi​), we must chose β0\beta_0β0​ and β1\beta_1β1​ so that predictions y^i\hat{y}_iy^​i​ match the data as closely as possible.

We quantify model quality with a loss function. A standard choice is the sum of squared errors between the predicted and observed values:

L=∑i=1N(yi−y^i)2=∑i=1N(yi−(β0+β1xi))2\mathcal{L} = \sum_{i=1}^N (y_i - \hat{y}_i)^2 = \sum_{i=1}^N (y_i - (\beta_0 + \beta_1 x_i))^2L=i=1∑N​(yi​−y^​i​)2=i=1∑N​(yi​−(β0​+β1​xi​))2
(27)

Fitting linear regression is therefore equivalent to minimizing L\mathcal{L}L, which is why this method is also called ordinary least squares.

On the choice of the loss function

There is acutally a reason why we chose this loss function here. Least squares has a probabilistic interpretation if we model each observation as

yi=β0+β1xi+εiy_i = \beta_0 + \beta_1 x_i + \varepsilon_iyi​=β0​+β1​xi​+εi​

with independent, identically distributed Gaussian errors

εi∼N(0,σ2).\varepsilon_i \sim \mathcal{N}(0, \sigma^2).εi​∼N(0,σ2).

Then

yi∣xi∼N(β0+β1xi,σ2)y_i \mid x_i \sim \mathcal{N}(\beta_0 + \beta_1 x_i, \sigma^2)yi​∣xi​∼N(β0​+β1​xi​,σ2)

and the single-observation density is

p(yi∣xi,β0,β1,σ2)=12πσ2exp⁡(−(yi−(β0+β1xi))22σ2).p(y_i \mid x_i, \beta_0, \beta_1, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - (\beta_0 + \beta_1 x_i))^2}{2\sigma^2} \right).p(yi​∣xi​,β0​,β1​,σ2)=2πσ2​1​exp(−2σ2(yi​−(β0​+β1​xi​))2​).

Assuming independence, the dataset likelihood is

L(β0,β1,σ2)=∏i=1Np(yi∣xi,β0,β1,σ2).L(\beta_0, \beta_1, \sigma^2) = \prod_{i=1}^N p(y_i \mid x_i, \beta_0, \beta_1, \sigma^2).L(β0​,β1​,σ2)=i=1∏N​p(yi​∣xi​,β0​,β1​,σ2).

Substituting the Gaussian density gives

L(β0,β1,σ2)=∏i=1N12πσ2exp⁡(−(yi−(β0+β1xi))22σ2)L(\beta_0, \beta_1, \sigma^2) = \prod_{i=1}^N \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(y_i - (\beta_0 + \beta_1 x_i))^2}{2\sigma^2} \right)L(β0​,β1​,σ2)=i=1∏N​2πσ2​1​exp(−2σ2(yi​−(β0​+β1​xi​))2​)

which simplifies to

L(β0,β1,σ2)=(2πσ2)−N/2exp⁡(−12σ2∑i=1N(yi−(β0+β1xi))2).L(\beta_0, \beta_1, \sigma^2) = (2\pi\sigma^2)^{-N/2} \exp\left( -\frac{1}{2\sigma^2} \sum_{i=1}^N (y_i - (\beta_0 + \beta_1 x_i))^2 \right).L(β0​,β1​,σ2)=(2πσ2)−N/2exp(−2σ21​i=1∑N​(yi​−(β0​+β1​xi​))2).

Taking logs,

log⁡L(β0,β1,σ2)=−N2log⁡(2πσ2)−12σ2∑i=1N(yi−(β0+β1xi))2.\log L(\beta_0, \beta_1, \sigma^2) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^N (y_i - (\beta_0 + \beta_1 x_i))^2.logL(β0​,β1​,σ2)=−2N​log(2πσ2)−2σ21​i=1∑N​(yi​−(β0​+β1​xi​))2.

The first term is constant in β0\beta_0β0​ and β1\beta_1β1​, so maximizing log-likelihood is equivalent to minimizing

∑i=1N(yi−(β0+β1xi))2,\sum_{i=1}^N (y_i - (\beta_0 + \beta_1 x_i))^2,i=1∑N​(yi​−(β0​+β1​xi​))2,

i.e. the least-squares objective.

In the section on Computational Optimisation you learned how to minimize any function numerically, but we can also apply some calculus here. Recall that at the optimum, ∂L∂β0=0\frac{\partial \mathcal{L}}{\partial \beta_0}=0∂β0​∂L​=0 and ∂L∂β1=0\frac{\partial \mathcal{L}}{\partial \beta_1}=0∂β1​∂L​=0 must hold. This gives the linear system

(N∑i=1N xi∑i=1N xi∑i=1N xi2)⏟A (β0β1)(∑i=1N yi∑i=1N xiyi)⏟β⃗=(∑i=1N yi∑i=1N xiyi)⏟b⃗\underbrace{ \begin{pmatrix} \displaystyle N & \displaystyle \sum_{i=1}^N\, x_i \\[1.5em] \displaystyle \sum_{i=1}^N\, x_i & \displaystyle \sum_{i=1}^N\, x_i^2 \end{pmatrix}}_{\displaystyle \bm{A}} \, \underbrace{ \begin{pmatrix} \displaystyle \beta_0 \\[1.5em] \displaystyle \beta_1 \end{pmatrix} \vphantom{ \begin{pmatrix} \displaystyle \sum_{i=1}^N\, y_i \\[1.5em] \displaystyle \sum_{i=1}^N\, x_i y_i \end{pmatrix} } }_{\displaystyle \vec{\beta}} = \underbrace{ \begin{pmatrix} \displaystyle \sum_{i=1}^N\, y_i \\[1.5em] \displaystyle \sum_{i=1}^N\, x_i y_i \end{pmatrix}}_{\displaystyle \vec{b}}A⎝⎛​Ni=1∑N​xi​​i=1∑N​xi​i=1∑N​xi2​​⎠⎞​​​β​⎝⎛​β0​β1​​⎠⎞​⎝⎛​i=1∑N​yi​i=1∑N​xi​yi​​⎠⎞​​​=b⎝⎛​i=1∑N​yi​i=1∑N​xi​yi​​⎠⎞​​​
(28)

which can be solved with numpy.linalg.solve or analytically to obtain the optimal weights.

Analytical solution

Write the normal equations as

Nβ0+(∑i=1Nxi)β1=∑i=1Nyi,(∑i=1Nxi)β0+(∑i=1Nxi2)β1=∑i=1Nxiyi.\begin{aligned} N\beta_0 + \left(\sum_{i=1}^N x_i\right)\beta_1 &= \sum_{i=1}^N y_i,\\ \left(\sum_{i=1}^N x_i\right)\beta_0 + \left(\sum_{i=1}^N x_i^2\right)\beta_1 &= \sum_{i=1}^N x_i y_i. \end{aligned}Nβ0​+(i=1∑N​xi​)β1​(i=1∑N​xi​)β0​+(i=1∑N​xi2​)β1​​=i=1∑N​yi​,=i=1∑N​xi​yi​.​

From the first equation,

β0=1N∑i=1Nyi⏟yˉ−1N∑i=1Nxi⏟xˉβ1=yˉ−β1xˉ.\beta_0 = \underbrace{\frac{1}{N}\sum_{i=1}^N y_i}_{\bar{y}} - \underbrace{\frac{1}{N}\sum_{i=1}^N x_i}_{\bar{x}}\beta_1 = \bar{y} - \beta_1\bar{x}.β0​=yˉ​N1​i=1∑N​yi​​​−xˉN1​i=1∑N​xi​​​β1​=yˉ​−β1​xˉ.

Insert this into the second equation and rearrange:

∑i=1Nxi(yi−yˉ)=β1∑i=1Nxi(xi−xˉ).\sum_{i=1}^N x_i\left(y_i-\bar{y}\right) = \beta_1 \sum_{i=1}^N x_i\left(x_i-\bar{x}\right).i=1∑N​xi​(yi​−yˉ​)=β1​i=1∑N​xi​(xi​−xˉ).

Equivalent centering in numerator and denominator gives

β1=∑i=1N(xi−xˉ)(yi−yˉ)∑i=1N(xi−xˉ)2.\beta_1 = \frac{\sum_{i=1}^N (x_i-\bar{x})(y_i-\bar{y})}{\sum_{i=1}^N (x_i-\bar{x})^2}.β1​=∑i=1N​(xi​−xˉ)2∑i=1N​(xi​−xˉ)(yi​−yˉ​)​.

Interpreting the results, we observe that the best fitted line always passes through the mean (xˉ,yˉ)(\bar{x},\bar{y})(xˉ,yˉ​) of the data, and that the optimal slope β1\beta_1β1​ is closely related to the Pearson correlation coefficient.

Linear Regression for Multi-dimensional Inputs¶

Very few real-world datasets can be described by a single scalar xxx; most are represented by vectors x⃗∈Rd\vec{x} \in \mathbb{R}^dx∈Rd. This includes reaction data (characterised by temperature, pressure, concentration, etc.) or molecular descriptors.

Terminology

In machine learning, the components of x⃗\vec{x}x are called features, ddd is the dimensionality, and the corresponding output yyy is the label or target. Slope and intercept are often referred to as weights and bias.

The linear model extends directly by assigning one weight to each feature dimension:

y^i=β0+β1xi1+β2xi2+⋯+βdxid=β0+β⃗⊤x⃗i\hat{y}_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_d x_{id} = \beta_0 + \vec{\beta}^\top \vec{x}_iy^​i​=β0​+β1​xi1​+β2​xi2​+⋯+βd​xid​=β0​+β​⊤xi​

Stacking the NNN feature vectors x⃗i\vec{x}_ixi​ into a matrix X∈RN×(d+1)\bm{X} \in \mathbb{R}^{N \times (d+1)}X∈RN×(d+1) lets us compute all predictions at once:

y⃗^=Xβ⃗\hat{\vec{y}} = \bm{X} \vec{\beta}y​^​=Xβ​

Here, the bias β0\beta_0β0​ is absorbed by adding a column of ones to the data matrix X\bm{X}X.

X=(1x11x12⋯x1d1x21x22⋯x2d⋮⋮⋮⋱⋮1xN1xN2⋯xNd)\bm{X} = \begin{pmatrix} 1 & x_{11} & x_{12} & \cdots & x_{1d} \\ 1 & x_{21} & x_{22} & \cdots & x_{2d} \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & x_{N1} & x_{N2} & \cdots & x_{Nd} \end{pmatrix}X=⎝⎛​11⋮1​x11​x21​⋮xN1​​x12​x22​⋮xN2​​⋯⋯⋱⋯​x1d​x2d​⋮xNd​​⎠⎞​
Derivation of the analytical solution

For the multi-dimensional model, the least-squares loss is

L=∑i=1N(yi−y^i)2=∥Xβ⃗−y⃗∥22.\mathcal{L} = \sum_{i=1}^{N}(y_i-\hat{y}_i)^2 = \lVert \bm{X}\vec{\beta}-\vec{y} \rVert_2^2.L=i=1∑N​(yi​−y^​i​)2=∥Xβ​−y​∥22​.

Differentiate with respect to β⃗\vec{\beta}β​:

∇β⃗L=∇β⃗((Xβ⃗−y⃗)⊤(Xβ⃗−y⃗))=2X⊤(Xβ⃗−y⃗).\nabla_{\vec{\beta}}\mathcal{L} = \nabla_{\vec{\beta}}\left((\bm{X}\vec{\beta}-\vec{y})^\top(\bm{X}\vec{\beta}-\vec{y})\right) = 2 \bm{X}^\top(\bm{X}\vec{\beta}-\vec{y}).∇β​​L=∇β​​((Xβ​−y​)⊤(Xβ​−y​))=2X⊤(Xβ​−y​).

Setting the gradient to zero yields

X⊤Xβ⃗^=X⊤y⃗.\bm{X}^\top\bm{X}\hat{\vec{\beta}}=\bm{X}^\top\vec{y}.X⊤Xβ​^​=X⊤y​.

If X⊤X\bm{X}^\top\bm{X}X⊤X is invertible (independent columns/features), the closed-form optimum is

β⃗^=(X⊤X)−1X⊤y⃗.\hat{\vec{\beta}}=(\bm{X}^\top\bm{X})^{-1}\bm{X}^\top\vec{y}.β​^​=(X⊤X)−1X⊤y​.

If we have more features than data points (d>Nd > Nd>N) or the features are linearly dependent, the matrix X⊤X\bm{X}^\top\bm{X}X⊤X is singular and we need to use the Moore-Penrose pseudoinverse.

Application¶

We now apply linear regression to a real dataset: absorbance of the methylene blue dye (target) measured at different concentrations (feature). From Lambert-Beer’s law, a linear relationship is expected, so a linear model is a reasonable starting point.

Fitting a linear model¶

Instead of solving the system of equations (28) manually, we can use numpy to compute the optimal weights directly. numpy.polyfit takes features, targets, and the polynomial degree (1 for linear regression), and returns the weights that minimize squared errors.

# Convert columns to numpy arrays
x = df['Concentration (µM)'].values
y = df['Absorbance'].values

# Fit the model
beta = np.polyfit(x, y, 1)
print(beta)
[ 0.03800109 -0.04907034]

Plotting the fitted line together with the data is straightforward.

x_range = np.linspace(x.min(), x.max(), 1000)
plt.plot(x, y, 'o', label='Data')
plt.plot(x_range, beta[0] * x_range + beta[1], label='Fitted line')
plt.xlabel('Concentration (µM)')
plt.ylabel('Absorbance')
plt.legend()
plt.show()
Warning

Note that numpy.polyfit returns the weights with highest degree first. Therefore, the bias is the last element of the returned array.

To quantify fit quality, we compute the loss (27), i.e. the sum of squared errors between targets and predictions.

print(np.sum((y - beta[0] * x - beta[1])**2))
0.0039732139069224666

Overfitting and Cross-Validation¶

Because the fitted line follows the data closely, there is no immediate reason to use a more complex model. In high-dimensional or otherwise complex real-world settings, however, predictions are often not directly visualizable and we may rely on loss values alone. To illustrate how this can create a false sense of security, we now fit a higher-degree polynomial. Instead of constructing the polynomial manually, we use numpy.polyval to evaluate it at arbitrary points.

# Fit the model
degree = 15
beta = np.polyfit(x, y, degree)

# Compute the loss
loss = np.sum((y - np.polyval(beta, x))**2)
print(loss)
4.887752923343191e-05

Since the loss is much lower than before, we might conclude that the model now describes the data better. However, plotting the polynomial with the data reveals the actual reason for the low loss.

plt.plot(x, y, 'o', label='Data')
plt.plot(x_range, np.polyval(beta, x_range), label=f'Fitted polynomial of degree {degree}')
plt.xlabel('Concentration (µM)')
plt.ylabel('Absorbance')
plt.legend()
plt.show()

When a model fits each data point, including noise, instead of the underlying trend, the result is called overfitting. This usually occurs when model complexity is too high for the structure or amount of available data. Detecting and mitigating it is a central task in machine learning! A standard diagnostic is cross-validation: split the data into training and test sets, train on the training set, and evaluate on the test set. Here, we shuffle sample indices with numpy.random.permutation and take the first 80% of data points as training data.

# Shuffle sample indices and take the first 80% for training
n_train = int(0.8 * len(x))
perm = np.random.permutation(len(x))
train_idx = perm[:n_train]
test_idx = perm[n_train:]

# Split the data
x_train, y_train = x[train_idx], y[train_idx]
x_test, y_test = x[test_idx], y[test_idx]

# Fit the model
beta = np.polyfit(x_train, y_train, degree)

# Compute the loss
train_loss = np.sum((y_train - np.polyval(beta, x_train))**2)
test_loss = np.sum((y_test - np.polyval(beta, x_test))**2)
print(f'Train loss: {train_loss}')
print(f'Test loss: {test_loss}')
Train loss: 1.3993534670417994e-11
Test loss: 7.988299369991336

The combination of high test loss and relatively low train loss indicates that the model has memorized the training data and does not generalize well to unseen data. The interactive plot below lets you explore this behavior in more detail, and the problem set discusses how regularization can be used to reduce overfitting.

import warnings
import altair as alt
import pandas as pd
from IPython.display import HTML, display
alt.data_transformers.disable_max_rows()

x = df['Concentration (µM)'].values
y = df['Absorbance'].values
# Keep total rows below Altair's default 5000-row limit for inline data.

DEGREE_MIN, DEGREE_MAX = 0, 20

# Reuse the same 100 splits for all slider positions.
rng = np.random.default_rng(42)
n_samples = len(x)
train_size = int(0.8 * n_samples)
splits = []
for _ in range(100):
    train_idx = rng.choice(n_samples, size=train_size, replace=False)
    test_idx = np.setdiff1d(np.arange(n_samples), train_idx)
    splits.append((train_idx, test_idx))


def compute_mean_losses(degree):
    train_losses = []
    test_losses = []
    for train_idx, test_idx in splits:
        x_train, y_train = x[train_idx], y[train_idx]
        x_test, y_test = x[test_idx], y[test_idx]
        with warnings.catch_warnings():
            warnings.simplefilter('ignore')
            beta = np.polyfit(x_train, y_train, degree)
        train_losses.append(np.sum((y_train - np.polyval(beta, x_train)) ** 2))
        test_losses.append(np.sum((y_test - np.polyval(beta, x_test)) ** 2))
    return np.mean(train_losses), np.mean(test_losses)


# Precompute curves and losses for all degrees (Jupyter Book friendly Altair slider).
