Was ist Programmieren?

Under Construction

Diese Seite befindet sich noch im Aufbau. Bitte haben Sie etwas Geduld, bis sie vollständig ist.

Programmieren bedeutet, einem Computer Anweisungen so aufzuschreiben, dass er sie Schritt für Schritt ausführen kann. Diese Anweisungen werden in einer Textdatei gespeichert und bilden zusammen ein Programm.

Ein Computer verarbeitet Informationen nach festen Regeln. Er “versteht” nicht, was wir meinen, sondern führt nur genau die Befehle aus, die ihm gegeben werden.

Python ist eine Programmiersprache, also eine bestimmte Art, solche Anweisungen zu formulieren. Sie ist gut lesbar und deshalb besonders geeignet, um die Grundlagen des Programmierens zu lernen.

Wenn Sie ein Python-Programm starten, liest der Computer den Code und arbeitet die Befehle der Reihe nach ab. So lassen sich Berechnungen automatisieren, Daten auswerten und wiederholbare Abläufe zuverlässig ausführen.
