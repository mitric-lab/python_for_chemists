4.1 Single-layer Neural Networks

Neural networks can be understood as an extension of linear models, especially logistic regression, to problems with non-linear decision boundaries. The central idea is to combine several simple classifiers into a more flexible model, an approach that has played an important role since the early history of machine learning.

Theoretical Foundations¶

Let us first revisit logistic regression, a linear model for binary classification. It models the probability of a binary outcome yiy_iyi​ from a linear combination of the features x⃗i\vec{x}_ixi​, and maps this value to the interval between 0 and 1 using the logistic function σ\sigmaσ:

P(yi=1∣x⃗i)=11+e−w⃗⊤x⃗i=σ(w⃗⊤x⃗i)P(y_i=1|\vec{x}_i) = \frac{1}{1 + e^{-\vec{w}^\top \vec{x}_i}} = \sigma(\vec{w}^\top \vec{x}_i)P(yi​=1∣xi​)=1+e−w⊤xi​1​=σ(w⊤xi​)

A model that assigns binary labels based on a linear combination of the input features is generally called a perceptron. Like all linear classifiers, a single perceptron can only model linear decision boundaries, which limits the types of problems it can solve. Figure 9 shows this model as a computational graph: the source nodes represent the input features xkx_kxk​, the edges multiply them by the weights wkw_kwk​, and the following nodes represent summation and label assignment by thresholding.

As before, we assume an implicit feature x0=1x_0 = 1x0​=1 so that the bias can be absorbed into the weight vector. The key idea behind neural networks is to stack nnn independent perceptrons into a single layer, each with its own weights wkjw_{kj}wkj​. The overall output is then computed as a weighted sum of the individual perceptron outputs using additional weights aja_jaj​, as illustrated in Figure 10.

Mathematically, the output of this single-layer network of perceptrons is

y^i=∑jnajσ(∑kdwkj(x⃗i)k)=a⃗⊤σ(W⊤x⃗i),\hat{y}_i = \sum_j^n a_j \sigma(\sum_k^d w_{kj} (\vec{x}_i)_k) = \vec{a}^\top \sigma(\bm{W}^\top \vec{x}_i),y^​i​=j∑n​aj​σ(k∑d​wkj​(xi​)k​)=a⊤σ(W⊤xi​),
(34)

where W∈Rd×n\bm{W} \in \mathbb{R}^{d \times n}W∈Rd×n is the matrix of perceptron weights and a⃗∈Rn\vec{a} \in \mathbb{R}^na∈Rn contains the weights of the final linear combination.

Artificial Neurons

Perceptrons are loosely inspired by biological neurons, which activate when a combination of input signals exceeds a threshold. For this reason, perceptrons are also called artificial neurons, and networks of such units are called artificial neural networks, or neural networks for short. However, neural networks do not necessarily mimic the operating principles of the human brain.

Training this simplest neural network means minimising a loss function over the training data, for example by gradient descent. Although we introduced the model in the context of binary classification, we first consider the mean squared error loss function,

L=12N∑iN(y^i−yi)2,\mathcal{L} = \frac{1}{2N} \sum_i^N \left(\hat{y}_i - y_i \right)^2,L=2N1​i∑N​(y^​i​−yi​)2,

where y^i\hat{y}_iy^​i​ is the unbounded neural network output and yi∈{−1,1}y_i \in \{-1, 1\}yi​∈{−1,1} is the true label. Gradient descent requires the derivative of the loss with respect to the weights. Applying the chain rule gives

∂L∂a⃗=1N∑iN(y^i−yi)σ(W⊤x⃗i)∂L∂W=1N∑iN(y^i−yi)(a⃗⊙σ′(W⊤x⃗i)x⃗i⊤)⊤.\begin{aligned} \frac{\partial \mathcal{L}}{\partial \vec{a}} &= \frac{1}{N} \sum_i^N \left(\hat{y}_i - y_i \right) \sigma(\bm{W}^\top \vec{x}_i) \\ \frac{\partial \mathcal{L}}{\partial \bm{W}} &= \frac{1}{N} \sum_i^N (\hat{y}_i - y_i) \left(\vec{a} \odot \sigma'(\bm{W}^\top \vec{x}_i) \vec{x}_i^\top \right)^\top. \end{aligned}∂a∂L​∂W∂L​​=N1​i∑N​(y^​i​−yi​)σ(W⊤xi​)=N1​i∑N​(y^​i​−yi​)(a⊙σ′(W⊤xi​)xi⊤​)⊤.​
(35)

Instead of computing the gradient from the entire dataset at every update, neural networks are typically trained with mini-batch gradient descent. In this approach, the weights are updated after evaluating (35) on a random subset of the training data BBB, called a batch.

Implementation¶

To implement the single-layer perceptron (SLP), we use object-oriented programming. In particular, the computation of σ\sigmaσ and σ′\sigma'σ′ is handled by a dedicated function class. The built-in __call__ method lets us call an instance of this class like a regular function, without explicitly calling __call__. In the context of neural networks, the logistic function σ\sigmaσ is also called the sigmoid activation function; it is plotted below.

class Sigmoid:
    def __call__(self, x):
        return 1 / (1 + np.exp(-x))

    def gradient(self, x):
        return self(x) * (1 - self(x))

The __init__ method of the SLP class initialises the activation function and stores the main model and training parameters: the hidden weights, the final linear weights, the number of epochs, the learning rate, and the batch size. The feedforward method then computes the network output according to (34) by passing the input through the hidden layer and forming the final weighted sum. The implementation is vectorised so that it works both for a single feature vector and for an entire data matrix.

class SLP:
    def __init__(self, dim=2, hidden_size=2, activation='Sigmoid', n_epochs=100, alpha=0.1, batch_size=5):
        self.weights = np.random.randn(dim + 1, hidden_size)
        self.linear_weights = np.random.randn(hidden_size)
        if activation == "Sigmoid":
            self.activation = Sigmoid()
        else:
            raise NotImplementedError(f"Activation function not implemented.")
        self.epochs = n_epochs
        self.alpha = alpha
        self.batch_size = batch_size
    
    def feedforward(self, x):
        z = x @ self.weights
        return self.activation(z) @ self.linear_weights

The central method is train, which implements the mini-batch training loop for a dataset X and labels y. The outer loop runs over the epochs, meaning the number of full passes through the training data.

Within each epoch, the current mini-batch is selected by slicing the training data with the current position i and the batch size self.batch_size. Since the gradient is accumulated over the whole mini-batch before the update, the gradients for both the hidden weights and the final linear weights are first initialised to zero. The inner loop then iterates over the data points in the batch, computes the contributions to the gradients with respect to W\bm{W}W and a⃗\vec{a}a, and adds them to the accumulated gradients. After the batch has been processed, both sets of weights are updated once.

    def train(self, X, y):        
        N = X.shape[0]
        for _ in range(self.epochs):
            # Iterate over batches
            for i in range(0, N, self.batch_size):

                # Define batch
                X_batch = X[i:i + self.batch_size]
                y_batch = y[i:i + self.batch_size]

                # Initialize gradients
                grad_w = np.zeros_like(self.weights)
                grad_lw = np.zeros_like(self.linear_weights)

                # Accumulate gradients over the batch
                for xi, yi in zip(X_batch, y_batch):
            
                    zi = np.dot(self.weights.T, xi)
                    d_inner = self.linear_weights * self.activation.gradient(zi)
                    residue = self.feedforward(xi) - yi

                    # Compute gradients
                    grad_w += residue * np.outer(d_inner, xi).T
                    grad_lw += residue * self.activation(zi)

                # Update parameters after each batch
                self.weights -= self.alpha / len(X_batch) * grad_w
                self.linear_weights -= self.alpha / len(X_batch) * grad_lw

The complete SLP class is shown below, including explanatory docstrings.

class SLP:
    """Single-layer perceptron with sigmoid hidden units.

    The model first maps the input features through a hidden layer of
    sigmoid-activated perceptrons and then combines the hidden outputs
    linearly to produce one unbounded scalar output.
    """

    def __init__(self, dim=2, hidden_size=2, activation='Sigmoid', n_epochs=100, alpha=0.1, batch_size=5):
        """Initialise weights, activation function, and training hyperparameters.

        Parameters
        ----------
        dim : int
            Number of input features, excluding the implicit bias feature.
        hidden_size : int
            Number of perceptrons in the hidden layer.
        activation : str
            Name of the activation function used in the hidden layer.
        n_epochs : int
            Number of full passes through the training data.
        alpha : float
            Learning rate used for the gradient descent updates.
        batch_size : int
            Number of samples used for each mini-batch update.
        """
        self.weights = np.random.randn(dim + 1, hidden_size)
        self.linear_weights = np.random.randn(hidden_size)
        if activation == "Sigmoid":
            self.activation = Sigmoid()
        else:
            raise NotImplementedError(f"Activation function not implemented.")
        self.epochs = n_epochs
        self.alpha = alpha
        self.batch_size = batch_size

    def feedforward(self, x):
        """Compute the network output for one input vector or a matrix of inputs."""
        z = x @ self.weights
        return self.activation(z) @ self.linear_weights

    def train(self, X, y):
        """Fit the network weights using mini-batch gradient descent.

        The gradients are accumulated over each mini-batch and then used
        to update both the hidden weights and the final linear weights.
        """
        N = X.shape[0]
        for _ in range(self.epochs):
            # Iterate over batches
            for i in range(0, N, self.batch_size):

                # Define batch
                X_batch = X[i:i + self.batch_size]
                y_batch = y[i:i + self.batch_size]

                # Initialize gradients
                grad_w = np.zeros_like(self.weights)
                grad_lw = np.zeros_like(self.linear_weights)

                # Accumulate gradients over the batch
                for xi, yi in zip(X_batch, y_batch):

                    zi = np.dot(self.weights.T, xi)
                    d_inner = self.linear_weights * self.activation.gradient(zi)
                    residue = self.feedforward(xi) - yi

                    # Compute gradients
                    grad_w += residue * np.outer(d_inner, xi).T
                    grad_lw += residue * self.activation(zi)

                # Update parameters after each batch
                self.weights -= self.alpha / len(X_batch) * grad_w
                self.linear_weights -= self.alpha / len(X_batch) * grad_lw

Application¶

Because of their expressive power and flexibility, single-layer neural networks can be applied to a wide range of problems, including both classification and regression. Here, we use them for the two concentric circles dataset from Problem Set 3. This dataset is not linearly separable, so logistic regression, or equivalently a single artificial neuron, would fail to describe the decision boundary.

class SLP:
    def __init__(self, dim=2, hidden_size=2, activation='Sigmoid', n_epochs=100, alpha=0.1, batch_size=5):
        self.weights = np.random.randn(dim + 1, hidden_size)
        self.linear_weights = np.random.randn(hidden_size)
        if activation == "Sigmoid":
            self.activation = Sigmoid()
        else:
            raise NotImplementedError(f"Activation function not implemented.")
        self.epochs = n_epochs
        self.alpha = alpha
        self.batch_size = batch_size
        self.weight_history = []
        self.linear_weight_history = []
        self.loss_history = []
        self.train_accuracy_history = []

    def feedforward(self, x):
        z = x @ self.weights
        return self.activation(z) @ self.linear_weights

    def predict(self, X):
        return np.where(self.feedforward(X) >= 0.0, 1, -1)

    def loss(self, X, y):
        return 0.5 * np.mean((self.feedforward(X) - y) ** 2)

    def store_history(self, X, y):
        self.weight_history.append(self.weights.copy())
        self.linear_weight_history.append(self.linear_weights.copy())
        self.loss_history.append(self.loss(X, y))
        self.train_accuracy_history.append(np.mean(self.predict(X) == y))

    def train(self, X, y):
        self.weight_history = []
        self.linear_weight_history = []
        self.loss_history = []
        self.train_accuracy_history = []

        N = X.shape[0]
        self.store_history(X, y)
        for _ in range(self.epochs):

            # Shuffle data
            indices = np.arange(N)
            np.random.shuffle(indices)
            
            # Iterate over batches
            for i in range(0, N, self.batch_size):

                # Define batch
                indices_batch = indices[i:i + self.batch_size]
                X_batch = X[indices_batch]
                y_batch = y[indices_batch]

                # Initialize gradients
                grad_w = np.zeros_like(self.weights)
                grad_lw = np.zeros_like(self.linear_weights)

                # Accumulate gradients over the batch
                for xi, yi in zip(X_batch, y_batch):

                    zi = np.dot(self.weights.T, xi)
                    d_inner = self.linear_weights * self.activation.gradient(zi)
                    residue = self.feedforward(xi) - yi

                    # Compute gradients
                    grad_w += residue * np.outer(d_inner, xi).T
                    grad_lw += residue * self.activation(zi)

                # Update parameters after each batch
                self.weights -= self.alpha / len(X_batch) * grad_w
                self.linear_weights -= self.alpha / len(X_batch) * grad_lw
                self.store_history(X, y)

We initialise the SLP with 10 hidden neurons and a batch size of 8. Since the training set contains 160 samples, each epoch is split into 20 mini-batches. After fitting the model with the train method, we evaluate its performance on the held-out test set.

Because the model is trained with the mean squared error loss, we implicitly treat the discrete labels as continuous during optimisation. Still, the classification boundary is the set of points where the unbounded network output is zero.

# Create instance of the single-layer neural network
slp = SLP(
    dim=2,
    hidden_size=10,
    activation='Sigmoid',
    n_epochs=100,
    alpha=0.1,
    batch_size=8
)

# Train the single-layer neural network
slp.train(X_train, y_train)

# Predict the labels of the test set
y_pred = np.where(slp.feedforward(X_test) >= 0.0, 1, -1)
print(f"Test accuracy: {np.mean(y_pred == y_test)}")

def decision_scores(grid_points, weights, linear_weights):
    hidden_values = slp.activation(grid_points @ weights)
    return hidden_values @ linear_weights


def contour_segments(x_grid, y_grid, values, level=0.0):
    segments = []

    def interpolate(p1, p2, v1, v2):
        if np.isclose(v1, v2):
            return p1
        t = (level - v1) / (v2 - v1)
        return p1 + t * (p2 - p1)

    for j in range(len(y_grid) - 1):
        for i in range(len(x_grid) - 1):
            points = np.array(
                [
                    [x_grid[i], y_grid[j]],
                    [x_grid[i + 1], y_grid[j]],
                    [x_grid[i + 1], y_grid[j + 1]],
                    [x_grid[i], y_grid[j + 1]],
                ]
            )
            corner_values = np.array(
                [
                    values[j, i],
                    values[j, i + 1],
                    values[j + 1, i + 1],
                    values[j + 1, i],
                ]
            )

            intersections = []
            for edge_start, edge_end in [(0, 1), (1, 2), (2, 3), (3, 0)]:
                v1 = corner_values[edge_start]
                v2 = corner_values[edge_end]
                if (v1 <= level < v2) or (v2 <= level < v1):
                    intersections.append(
                        interpolate(points[edge_start], points[edge_end], v1, v2)
                    )

            if len(intersections) == 2:
                segments.append(intersections)
            elif len(intersections) == 4:
                segments.append(intersections[:2])
                segments.append(intersections[2:])
    return segments
