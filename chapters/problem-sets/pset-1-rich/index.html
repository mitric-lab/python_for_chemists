A: Regression as an Optimisation Problem¶

A common task in data analysis is to fit a model to data, which is called regression. Typically, we have a model with some parameters θ\thetaθ and a dataset of input-output pairs (xi,yi)(x_i, y_i)(xi​,yi​). The goal of regression is to find the parameters θ\thetaθ that best explain the data.

We shall write the data, consisting of NNN observations, as

x=(x1,x2,…,xN)y=(y1,y2,…,yN)\begin{align*} x &= (x_1, x_2, \ldots, x_N) \\ y &= (y_1, y_2, \ldots, y_N) \end{align*}xy​=(x1​,x2​,…,xN​)=(y1​,y2​,…,yN​)​

and the model as

y^i=f(θ;xi)for i=1,2,…,N .\hat{y}_i = f(\theta; x_i)\quad \text{for}\ i = 1, 2, \ldots, N \, .y^​i​=f(θ;xi​)for i=1,2,…,N.

A common way to make the model fit the data as well as possible is to minimise the sum of squared residuals, defined as

L(θ;x,y)=∑i=1N(yi−y^i)2=∑i=1N(yi−f(θ;xi))2 ,L(\theta; x, y) = \sum_{i=1}^N (y_i - \hat{y}_i)^2 = \sum_{i=1}^N (y_i - f(\theta; x_i))^2 \, ,L(θ;x,y)=i=1∑N​(yi​−y^​i​)2=i=1∑N​(yi​−f(θ;xi​))2,

leading to the so-called least-squares method.

In this way, we have turned the regression problem into an optimisation problem, where the objective function to be minimised is the loss function L(θ;x,y)L(\theta; x, y)L(θ;x,y).

When a linear model is used, i.e., f(θ;xi)=θ0+θ1xif(\theta; x_i) = \theta_0 + \theta_1 x_if(θ;xi​)=θ0​+θ1​xi​ with θ=(θ0,θ1)\theta = (\theta_0, \theta_1)θ=(θ0​,θ1​), the loss function can be implemented as

def linear_objective(theta, x, y):

def finite_difference_gradient(func, x_vec, h=1e-6):
    ndim = len(x_vec)
    grad = np.zeros(ndim)

    for i in range(ndim):
        e_i = np.zeros(ndim)
        e_i[i] = 1.0
        grad[i] = (
            func(x_vec + h * e_i) - func(x_vec - h * e_i)
        ) / (2 * h)

    return grad


def gradient_descent(func, x0, alpha=0.01, gtol=1e-6, maxiter=10000):
    x_vec = np.copy(x0)

    for niter in range(1, maxiter + 1):
        grad = finite_difference_gradient(func, x_vec)

        if np.linalg.norm(grad) < gtol:
            break

        x_vec = x_vec - alpha * grad

    return x_vec, niter

Gradient descent only uses the current gradient to determine the next step. In a narrow valley, this can lead to slow zig-zag motion. Momentum gradient descent adds a velocity vector that accumulates information from previous steps:

v⃗ k+1=γv⃗ k−α∇f(x⃗ k) ,\vec{v}^{\,k+1} = \gamma \vec{v}^{\,k} - \alpha \nabla f(\vec{x}^{\,k}) \, ,vk+1=γvk−α∇f(xk),

x⃗ k+1=x⃗ k+v⃗ k+1 .\vec{x}^{\,k+1} = \vec{x}^{\,k} + \vec{v}^{\,k+1} \, .xk+1=xk+vk+1.

Here, α\alphaα is the step size and γ\gammaγ is the momentum parameter. For γ=0\gamma = 0γ=0, the method reduces to ordinary gradient descent.
