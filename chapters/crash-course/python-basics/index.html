0.1 Python Basics

Welcome! This notebook is a simple, entry-level introduction to Python.

Learning goals¶

By the end of this notebook, you will be able to:

  • run and edit Jupyter notebook cells,

  • define and use variables,

  • work with basic operators,

  • use lists, tuples, and dictionaries,

  • write if/elif/else statements,

  • write and understand basic loops.

1) How to use Jupyter notebooks¶

A Jupyter notebook is a document made of cells.

  • Markdown cells contain explanations.

  • Code cells contain Python code you can run.

To start Jupyter from your project folder, run:

jupyter notebook

Go ahead and try the following steps yourself. You can download this notebook by clicking , which can be found in the top right corner of the page.

Basic navigation and execution¶

In a Jupyter notebook, you can be in one of two modes: Command mode (cell is highlighted in blue) or Edit mode (cursor blinks additionally).

  • Press Enter to edit a selected cell.

  • Press Esc to leave edit mode.

  • Press Shift+Enter to run the current cell.

  • In command mode, press B to add a new cell below and A to add one above.

  • In command mode, press M for markdown or Y for code.

  • In command mode, press X to delete a cell.

Try running the next cell:

print("Hello, notebook!")
Hello, notebook!

Why execution order matters¶

The kernel, which is the background process that runs your code, keeps state. If a variable is created in one cell, later cells can use it. Run the next two code cells in order.

message = "Python is running in this kernel."
print(message)
Python is running in this kernel.

If you restart the kernel, variables are cleared and must be created again.

That is why running cells in a clear top-to-bottom order is important.

2) Variables and primary data types¶

A variable stores a value. You create a variable with =.

In this notebook, we use these primary types:

  • str (text)

  • int (whole numbers)

  • float (decimal numbers)

  • bool (True or False)

  • None (no value yet)

city = "Hannover"  # str
year = 2026  # int
temperature = 21.5  # float
is_sunny = True  # bool
result = None  # NoneType

print(city, type(city))
print(year, type(year))
print(temperature, type(temperature))
print(is_sunny, type(is_sunny))
print(result, type(result))
Hannover <class 'str'>
2026 <class 'int'>
21.5 <class 'float'>
True <class 'bool'>
None <class 'NoneType'>

A variable must be created before you can use it. The next example shows what happens when a name is missing.

3) Operators¶

Operators combine or compare values.

Arithmetic operators¶

Use arithmetic operators +, -, *, /, //, %, ** to calculate new numbers from existing variables. For example, a + b adds two values and returns the result, which could be stored in a new variable.

Useful notes:

  • / gives a float result.

  • // is floor division (integer-like quotient).

  • % gives the remainder.

  • ** means power (for example 2**3 = 8).

a = 10
b = 3

print("a + b =", a + b)
print("a - b =", a - b)
print("a * b =", a * b)
print("a / b =", a / b)
print("a // b =", a // b)
print("a % b =", a % b)
print("a ** b =", a**b)
a + b = 13
a - b = 7
a * b = 30
a / b = 3.3333333333333335
a // b = 3
a % b = 1
a ** b = 1000

Relational operators¶

Relational operators compare two values and always return a boolean (True or False). They are often used inside if statements.

Use relational operators to compare values:

  • == checks for equality.

  • != checks for inequality.

  • >, <, >=, <= compare numerical values.

x = 7
y = 10

print("x == y:", x == y)
print("x != y:", x != y)
print("x > y:", x > y)
print("x < y:", x < y)
print("x >= 7:", x >= 7)
print("y <= 9:", y <= 9)
x == y: False
x != y: True
x > y: False
x < y: True
x >= 7: True
y <= 9: False

You can combine relational operators with and, or, and not to check multiple conditions.

print("x == 7 and y == 10:", x == 7 and y == 10)
print("x == 7 or y == 1:", x == 7 or y == 1)
print("not x == 7:", not x == 7)
x == 7 and y == 10: True
x == 7 or y == 1: True
not x == 7: False

4) Data containers¶

Containers hold multiple values. Some examples are:

  • List: ordered, mutable, initialised with square brackets []

  • Tuple: ordered, immutable, initialised with parentheses ()

  • Dictionary: key-value pairs, mutable, initialised with curly braces {}

Basic access patterns:

  • List and tuple elements are accessed by index, for example colours[0].

  • Dictionary values are accessed by key, for example student["name"].

A quick reminder:

  • Indexing starts at 0.

  • Negative indices access from the end (for example colours[-1]).

colours = ["red", "green", "blue"]
print(colours[0])

# Basic list method
colours.append("yellow")
print(colours)
red
['red', 'green', 'blue', 'yellow']

point = (2.0, 5.0)
print(point)

# Tuples are immutable, so changing an item causes an error
point[0] = 10.0
(2.0, 5.0)

5) If/elif/else statements¶

Use if/elif/else to run different code depending on a condition.

How it works:

  • if checks the first condition.

  • elif checks additional conditions if needed.

  • else runs when no earlier condition is True.

Syntax reminders:

  • Each condition line ends with a colon :.

  • The code block below it must be indented.

score = 72

if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"

print("Grade:", grade)
Grade: C

temperature = 18
is_raining = False

if temperature > 15 and not is_raining:
    print("Good day for a walk.")
else:
    print("Better take a jacket.")
Good day for a walk.

6) Loops¶

Loops repeat code.

  • Use for when iterating over a sequence (like a list, tuple, string, or range).

  • Use while when repeating until a condition becomes false.

Context:

  • In for item in sequence:, item is the loop variable.

  • range(n) produces numbers from 0 to n-1.

  • As with if blocks, loop bodies need indentation.

for colour in ["red", "green", "blue"]:
    print("Colour:", colour)
Colour: red
Colour: green
Colour: blue

for i in range(3):
    print("i =", i)
i = 0
i = 1
i = 2

counter = 0

while counter < 3:
    print("counter =", counter)
    counter += 1
counter = 0
counter = 1
counter = 2

A nested loop means one loop runs inside another.

for row in range(1, 3):
    for col in range(1, 4):
        print(f"row={row}, col={col}")
row=1, col=1
row=1, col=2
row=1, col=3
row=2, col=1
row=2, col=2
row=2, col=3

In a for-else pattern, the else block runs if the loop finishes without break.

numbers = [2, 4, 6, 9]

for value in numbers:
    if value % 2 != 0:
        print("Found an odd number:", value)
        break
else:
    print("All numbers are even.")
Found an odd number: 9
