# Problem Set Pages (Generated)

This directory contains the generated **rich** problem set notebooks that are used to
render the published problem set pages in the book (e.g. `pset_1_rich.ipynb`).

They are generated by `scripts/generate_student_notebooks.py` and are intentionally
**not** tracked in git.

The corresponding **clean** notebooks for students to download live in:
`assets/downloads/problem_sets/`.
