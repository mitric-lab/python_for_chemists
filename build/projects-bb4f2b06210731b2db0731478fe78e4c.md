# Projects

During the project phase, you will work in groups of 2&ndash;3 students and apply methods from the course to a real-world problem of your choice.

We will be available during the usual lecture times to answer questions and help with problems. The Jupyter Notebook you use for the project (see {ref}`sec:project_template`) will also serve as your project report and will be published on this website. At the end of the project phase, each group will briefly present its project and results to the class (about 15 minutes).

| Section | Content |
| ------- | ------- |
| Template | Notebook template for the project report |
| Manganate Decay | Fitting absorbance data for the decay of tris(oxalato)manganate(III) |
| TLC Mobile Phase Prediction | Predicting TLC mobile phase compositions for organic molecules |
| Spectra Classification | Classifying chemical samples from IR spectra |
| Solubility Prediction | Predicting aqueous solubility from molecular structure |
| Electrolyte Identification | Inferring ionic solution composition from conductivity data |
