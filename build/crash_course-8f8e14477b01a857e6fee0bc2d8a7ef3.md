# 0&emsp14;&emsp14;Crash Course

This chapter provides a beginner-friendly introduction to Python for students who may be programming for the first time.

It introduces the Jupyter notebook workflow, basic Python syntax and control structures, the core ideas behind functions and classes, numerical work with NumPy, and data visualisation with Matplotlib. The goal is to build enough confidence and vocabulary to work productively with the later lecture notes and exercises.

The accompanying problem set is published as a notebook at {ref}`sec:pset_0`. Use the download button at the top of that page to save a local copy.

| Section | New Concepts and Tools |
| --- | --- |
| Python Basics | Jupyter cells and execution, variables and types, operators, lists, tuples, dictionaries, `if` / `elif` / `else`, `for`-loops |
| Functions and Classes | `def`, `return`, arguments and default arguments, scope, `lambda`, classes (`__init__`, methods, instances) |
| Numerical Programming | `import numpy as np`, arrays vs lists, `np.arange`, `np.linspace`, `shape`, `reshape`, indexing and slicing, elementwise operations, dot products and `np.linalg` |
| Visualising Data | `matplotlib.pyplot`, `plt.plot`, line and marker styles, axis labels, titles, limits, legends, `plt.subplots` |
