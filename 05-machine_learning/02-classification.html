Classification

From the previous section, we have seen that finding a line (or hyperplane) through your data, consisting of features and targets, already is the simplest form of supervised learning. You should, however, apply regression only if the targets are continuous, e.g. the intensity of a fluorescence signal. For discrete targets that originate from a finite set of labels, we call this classification and we will discuss in this chapter how to effectively tackle such a problem.

Formally, the abstract goal of classification is to find a function f^​w​:Rd→{1,2,…,K} that maps the input x∈Rd to one of K classes, such that most of the N data points are assigned to the correct class yi​∈{1,2,…,K}. We will focus on the simplest case, binary classification, where the data can be assigned to two possible classes yi​∈{−1,+1}. An example of such a problem is the prediction of whether a given image contains a cat or a dog, or whether a given molecule is toxic or not.

Rosenblatts Perceptron

Let us tackle this problem with the same concepts in mind that we defined in the previous section, namely identifying a model, a loss function and an optimisation algorithm.

We define the model as a linear function of the input features:

f^​w​(x)=sign(⟨w,x⟩+b),

which we can again simplify to

f^​w​(x)=sign(⟨w,x⟩),

by including the bias b as the last element of the weight vector w and adding 1 to the feature vector x. The sign(z) function returns 1 if z>0, -1 otherwise. Therefore, the model assigns the class 1 to all data points x for which ⟨w,x⟩>0 and the class -1 to all data points for which ⟨w,x⟩≤0.

Secondly, we need to define a loss function that quantifies how well the model performs. A natural choice is

L=i=1∑N​max(0,−yi​⟨w,xi​⟩),

where max(0,z) returns 0 if z≤0 and z otherwise. Let us contemplate for a moment why this loss function is a good choice. Consider the case where we have a input xi​ that is misclassified. This can happen in two ways:

  1. ⟨w,xi​⟩>0 and yi​=−1.
  2. ⟨w,xi​⟩≤0 and yi​=1.

In both cases, the i-th part of the loss function is greater than 0. On the other hand, if the data point is correctly classified, the loss function for this data point is 0, which is exactly what we want. Consequently, we can only achieve a minimal loss of 0 if the data points are linearly separable, i.e. if there exists a hyperplane that completely separates the two classes.

Finally, we need to define an optimisation algorithm that finds the weights w that minimise the loss function. The simplest algorithm is the gradient descent, which we have already seen in the first section. However, we have to be careful here, as the loss function is not differentiable when ⟨w,xi​⟩=0. We can, however, compute subgradients of the non-zero parts of the loss function:

∇w​(−yi​⟨w,xi​⟩)=−yi​xi​,

that give rise to the following update rule:

w←w+ηyi​xi​,

where η is the learning rate. Put together, we need to iterate over all misclassified data points (loss is greater than 0) and update the weights according to the update rule. Remember that we can easily check if a data point xi​ is misclassified by comparing the prediction f^​w​(xi​) with the true label yi​.
