Exercise 1 [Homework]: Hückel Theory

From quantum mechanics, you’re familiar with the LCAO (Linear Combination of Atomic Orbitals) method for constructing molecular orbitals. Hückel theory provides a simplified version specifically for conjugated π systems, focusing on the π-electrons that largely determine these molecules’ electronic properties. In this theory, each Hückel molecular orbital φi​ is built from the pz​ orbitals ϕμ​ of the N heavy atoms in the conjugated system:

φi​=μ=1∑N​cμi​ϕμ​ for i=1,…,N.​(1)​

To obtain the coefficients cμi​, we need to solve the Schrödinger equation for each molecular orbital φi​. Hückel theory simplifies this quantum mechanical problem by making three key approximations:

  1. The atomic pz​ orbitals are orthogonal: Sμν​=∫ϕμ​ϕν​dr=δμν​
  2. The interaction (resonance) integral between bonded atoms is a constant: Hμν​=∫ϕμ​H^ϕν​dr=β if atoms μ and ν share a bond, and zero otherwise
  3. All Coulomb integrals are equal: Hμμ​=α for all atoms

(a) Deriving the Eigenvalue Problem

Show that these approximations reduce the Schrödinger equation to a matrix eigenvalue problem:

Hc=cE

where:

  • H is the Hamiltonian (Hückel) matrix
  • c contains the orbital coefficients cμi​ as columns
  • E is the diagonal matrix of orbital energies ϵi​

(b) Building the Hückel Matrix

For benzene, construct the Hückel matrix using the following steps:

  1. Download the molecular structure file benzene.xyz
  2. Determine which atoms are bonded by calculating a connectivity matrix from the atomic coordinates
  3. Convert this connectivity matrix into the Hückel matrix by setting:
    • Diagonal elements to α=0
    • Off-diagonal elements to β=−1 for bonded atoms
    • All other elements to zero

Tip

To calculate the connectivity matrix, you’ll need to:

  1. Read the coordinates of the heavy atoms from the xyz file
  2. Calculate distances between all pairs of atoms
  3. Set matrix elements to 1 if the distance is below a bonding threshold

To simplify this process, you can use the pre-implemented functions from this utils.py file. By placing it in the same directory as your Jupyter notebook, you can import the functions as follows:

from utils import read_xyz, get_connectivity_matrix

# Read structure (returns list of [atomic_number, x, y, z])

# Get connectivity matrix (1 for bonded atoms, 0 otherwise)
connectivity_matrix = get_connectivity_matrix(atoms)

(c) Evaluating Atomic Orbitals on a Grid

To construct and visualize the molecular orbitals, we first need to evaluate the atomic orbitals in 3D space. For the pz​ orbital centered on atom μ, use the unnormalized form:

ϕμ​(x,y,z)=(z−zμ​)e−r

where r=(x−xμ​)2+(y−yμ​)2+(z−zμ​)2​ is the distance from point (x,y,z) to atom μ at (xμ​,yμ​,zμ​). Note that the pz​ orbital is just a real-valued function on R3. So we would need to evaluate it at a grid of points in 3D space, which can be created using np.meshgrid.

Tip

Creating a 3D grid using np.meshgrid can be very confusing, so here’s a guidline:

  1. Create three 1D arrays for x, y, and z coordinates. Select the range and spacing of the grid points based on the size of the molecule.
  2. Use np.meshgrid to create 3D coordinate arrays. See these examples for detailed guidance on using meshgrid correctly.
  3. Note that you will get three separate arrays, which you will use as arguments to evaluate the orbital functions at all points at once.
  4. Do this for all six atoms in the benzene molecule, and save the atomic orbitals in a list.

(d) Calculating Molecular Orbitals

Now we can construct the molecular orbitals:

  1. Calculate orbital energies and coefficients by diagonalizing the Hückel matrix using np.linalg.eigh
  2. Construct the molecular orbitals from the atomic orbitals according to equation (1).

Tip

Therefore, first create an empty list, where you will store the molecular orbitals. Then, iterate over all six molecular orbitals φi​, and for each one, compute the weighted sum of the atomic orbitals ϕμ​ according to equation (1) with the coefficients cμi​, again using a for loop.
